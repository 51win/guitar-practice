# 기타 연습

데스크톱과 태블릿을 위한 기타 연습 도구입니다. 설치와 로그인 없이 브라우저에서 실행합니다.

- 보이싱, 쉘 보이싱, 트라이어드, 코드톤, 메이저·마이너 펜타토닉
- 지판 아래 프렛 번호로 기준 위치 선택
- 현재 코드부터 이어지는 4개 코드 미리보기
- 1·2·3·4 박자별 메트로놈 켜기·끄기와 반주
- 개인 설정에서 홈 11칸(3·4·4)의 항목과 색상 선택
- 내 곡 → 새 곡 → 마디 더블클릭으로 코드 편집 → 곡 저장
- 마디당 1개, 2개, 4개 코드 지원. 태블릿에서는 마디를 선택하고 ‘마디 편집’을 누릅니다.

곡, 작성 중인 진행, 홈 설정과 연습 기록은 각 브라우저에 저장됩니다. 다른 사용자나 기기에 자동으로 공유되지 않습니다.

`index.html`을 직접 열거나 정적 웹 서버에서 실행할 수 있습니다. 로직 검사는 `node check.mjs`로 실행합니다.

폰트의 저작권과 사용 조건은 `fonts/`의 라이선스 파일을 참고하세요. 코드 진행 자료의 출처는 앱 안에 표시되어 있습니다.
