# 기타 연습

데스크톱과 태블릿을 위한 기타 연습 도구입니다. 설치와 로그인 없이 브라우저에서 실행합니다.

- 보이싱, 쉘 보이싱, 트라이어드, 코드톤, 메이저·마이너 펜타토닉
- 지판 아래 프렛 번호로 기준 위치 선택
- 현재 코드부터 이어지는 4개 코드 미리보기. ←/→는 마디 안의 코드까지 차례로 이동합니다.
- 코드톤 / 솔로 → 스케일 함께 보기: 스케일 음은 작은 원, 코드톤은 큰 원. 코드 종류별 기본값과 각 마디별 선택을 저장합니다.
- 보이싱·트라이어드 범위: ±3·5·7·9프렛
- 1·2·3·4 박자별 메트로놈 켜기·끄기와 반주
- 개인 설정에서 홈 11칸(3·4·4)의 항목과 색상 선택
- 내 곡 → 새 곡 → 마디 더블클릭으로 코드 편집 → 곡 저장
- 내 곡에서 이름·키·코드 검색, 직접 추가한 곡 삭제
- 공용 채팅에서 가입 없이 닉네임으로 메시지 공유
- 마디당 1개, 2개, 4개 코드 지원. 태블릿에서는 마디를 선택하고 ‘마디 편집’을 누릅니다.

곡, 작성 중인 진행과 홈 설정은 각 브라우저의 `localStorage`에 저장됩니다. 직접 추가한 곡은 공개 저장소로 전송되지 않으며 다른 사용자나 기기에 보이지 않습니다. 공용 채팅 메시지는 Netlify Functions와 Blobs에 저장되어 모든 방문자에게 공유됩니다.

`index.html`을 직접 열거나 정적 웹 서버에서 실행할 수 있습니다. 로직 검사는 `node check.mjs`로 실행합니다.

폰트의 저작권과 사용 조건은 `fonts/`의 라이선스 파일을 참고하세요. 코드 진행 자료의 출처는 앱 안에 표시되어 있습니다.

## 곡과 악보 따라가기

재즈 스탠다드 10곡: Fly Me to the Moon, Autumn Leaves, Blue Bossa, All of Me, Satin Doll, Take the “A” Train, Solar, Lady Bird, Recorda Me, So What. 각 곡의 출처 및 단순화한 부분은 연습 화면 아래에 표시합니다. 재즈 스탠다드에는 코드 진행만 포함되어 있습니다.

내 곡 → Silhouette → 펜타토닉 → 재생으로 악보의 줄·프렛을 따라갑니다. 기본 템포는 183 BPM, 총 178마디입니다. 구간 메뉴로 이동하거나 구간 반복을 설정할 수 있습니다. 마지막 마디 뒤에는 정지하며, 반복을 선택한 경우 해당 구간을 반복합니다. 악보 따라가기를 끄면 일반 펜타토닉 연습으로 돌아갑니다. 가이드 음과 반주는 독립적으로 켜고 끌 수 있습니다.

사용자가 제공한 6장의 악보에서 운지와 길이를 수동 입력했습니다. 슬라이드, 벤딩, 하모닉스, 트레몰로는 주법을 표시하고, 피아노 가이드 음으로 음정과 리듬을 확인합니다. 원곡 녹음이나 기타 주법의 사실적인 합성이 아닙니다. 사진 원본과 가사는 사이트에 포함하지 않습니다. 악보 운지 데이터는 `repertoire.js`에 있습니다. 원키를 바꾸면 음정을 이조하고 0~22프렛 안의 위치로 옮깁니다.
